# Iris Flower Classification

## Objective
Build a machine learning classification model to identify Iris flower species as Setosa, Versicolor, or Virginica.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Project Steps
1. Load the Iris dataset using Scikit-learn.
2. Perform Exploratory Data Analysis (EDA).
3. Check shape, data types, null values and statistics.
4. Visualize the dataset using pairplot and boxplots.
5. Train Logistic Regression and K-Nearest Neighbors models.
6. Evaluate the models using accuracy, confusion matrix and classification report.
7. Compare the models and select the best-performing model.
8. Demonstrate a final Iris flower prediction.

## Results
The trained machine learning models successfully classify Iris flower species.

## Output Screenshots
- Pairplot
- Boxplots
- Confusion Matrices
- Model Comparison
- Final Prediction

## Conclusion
The project demonstrates how machine learning classification can be used to identify Iris flower species based on their flower measurements.
